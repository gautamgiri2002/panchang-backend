# Uchchaith Panchang API Backend

Node.js backend proxy for Prokerala Panchang API.

## Render settings

Build Command:
npm install

Start Command:
npm start

## Environment Variables

PROKERALA_CLIENT_ID
PROKERALA_CLIENT_SECRET
PORT
